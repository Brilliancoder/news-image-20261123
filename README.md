Entry for the make.fun bounty **news-image-20261123**: the world's news of
Monday 23 November 2026 in one 1024x1024 image.

- `main.py` (Python 3.13, stdlib only) copies `entry.png` to `/output/entry.png`
  (or `$MAKEFUN_OUTPUT_DIR`). No network, same bytes every run.
- `build.py` re-renders `entry.png` at build time (needs Pillow and Noto fonts).
